# Hospital Patient Data Analyzer

## About the Project
A Python-based project that analyzes hospital patient data.

## Features
- Removes duplicate records
- Handles missing data
- Analyzes patient age and gender
- Calculates average hospital stay
- Shows department-wise analysis
- Generates charts using Matplotlib

## Technologies Used
- Python
- Pandas
- Matplotlib
- CSV

## How to Run
1. Install required libraries:
   pip install pandas matplotlib

2. Run the Python file:
   python hospital_patient_data_analyzer_code.py
